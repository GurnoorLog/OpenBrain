# PowerPoint (PPTX) Presentations

## Overview

Plan a clear narrative arc, then convert dense content into a scannable bullet hierarchy. Every slide has one message.

## Structure

1. **Title slide** — topic + presenter context
2. **Agenda** — what will be covered
3. **3–5 key sections** — each with a header slide + content slides
4. **Conclusion** — recap + call to action

## Rules

- **3–7 bullets per slide**, one idea per bullet, parallel phrasing, no walls of text
- Consistent visual system: one accent color, one title style, aligned layouts, legible hierarchy (titles large and bold)
- Text legible at 12pt+; no orphan bullets
- Every slide has speaker notes describing the spoken element
- Use section headers to group related content

## Output

Deck outline with slide-by-slide titles, bullets, and speaker notes ready to render as `.pptx`.
